# AGENTS.md - tennis

Shared conventions for agents working in this repo (owner: Tennibot). Keep changes small and local unless Tim says otherwise.

## Layout

- `DataPull/` - fetch scripts (polite, resumable, year-aware filenames under `data/raw/<source>/`)
  - `PullSackmann.py` - Jeff Sackmann ATP/WTA match CSVs (tour, qualifying/Challenger, ITF/Futures) + Grand Slam point-by-point. Default source is the archival mirror `Aneeshers/tennis-sackmann-archive` (the original JeffSackmann repos 404 since ~2026-10-14; mirror snapshot = June 2026). CC BY-NC-SA 4.0.
  - `PullKalshi.py` - Kalshi public API (read-only, no auth): tennis match markets, milestone start times, 1-min bid/ask candles.
  - `PullTennisData.py` - tennis-data.co.uk odds: MANUAL browser download by Tim + local ingest. The site blocks scripted access (HTTP 403) and says its data is not for bots/scrapers/AI, so never script downloads from it.
  - `Http.py` - shared polite session (never retries 401/403).
- `Backtest/` - leak-free models and backtests
  - `LoadMatches.py` - one chronologically ordered table per tour; level tags tour / tour_qual / challenger / itf; walkovers dropped
  - `Elo.py` (surface Elo), `ServeReturn.py` (serve/return points model), `Markov.py` (point->game->tiebreak->set->match, live states)
  - `Engine.py` - chronological walk; predictions per (tourney_date, round stage) group from the pre-group snapshot
  - `RunBacktest.py` - grid search on tune seasons, validation pick, freeze, frozen run
  - `ValidateMarkov.py` - in-play calibration on slam point-by-point (holdout 2022-2024)
  - `KalshiJoin.py`, `KalshiReality.py` - Kalshi pre-match quotes joined to matches; bets/CLV at Kalshi prices
  - `TennisDataOdds.py` - Pinnacle/Max/Avg scoring once tennis-data files are present
  - `PredictDay.py` - daily slate (Kalshi) -> two Markdown tables; `FrozenParams.py` (generated by `WriteFrozenParams.py`)
  - `Report.py` - writes the AgentDocs deliverable from finished outputs
  - `MarketBlend.py`, `RunMarketBlend.py` - log-loss gap vs Kalshi, walk-forward market blend, $10k bankrolls off p_blend; writes `E:\AgentDocs\Tennibot\<date>_market-blend\`
  - `ServeReturnElo.py`, `RunServeReturnElo.py` - prototype Elo-style serve/return ratings (defaults not tuned on holdout)
  - `KalshiLiquidity.py` - tour vs Challenger / WTA 125 liquidity survey (local files by default; `--refresh` is a read-only public API pull)
- `LiveOdds/` - `KalshiPublic.py` (read-only client), `Report.py` (live JSONL contract for Degen). No orders.
- `tests/` - unittest (leak tests, Markov, odds, names)
- `data/` - local only (gitignored): raw pulls, processed parquet, backtest outputs, prediction logs
- `logs/` - job logs (gitignored); `RunJob.ps1` starts a module in the background with a traceable first line

## Conventions

- Functions / classes / module files: PascalCase. Variables: snake_case.
- Code and docs in git; data stays local (`/data/`, `*.json`, `*.jsonl`, `*.parquet`, `.venv/`, `/logs/`).
- **No look-ahead.** Matches are walked by tourney_date then round stage; every match in a (date, stage) group is predicted from the snapshot taken before the group, and results are applied only afterwards. Never use same-tournament later rounds. Keep `tests/test_no_lookahead.py` passing whenever the engine changes.
- Splits: tune 2010-2019, validation 2020-2022, holdout 2023-2025 (untouched by the search), forward 2026. Rank configs by worst season; report how many configs were tried.
- **Default PASS.** PredictDay shows BET only when a quote with size exists, edge > 0 after fees, both players are rated, and ratings are fresh (last result within 14 days).
- Fee for edge math: **ask + 0.02** per $1 contract (Tim's estimate; not a verified fee). Kalshi's verified taker fee `0.07*p*(1-p)` is reported alongside where Kalshi prices are used.
- Live: action is **PASS** unless the in-play model is validated on holdout AND the quote is qualified AND price/state are fresh (<= 45 s) AND edge > 0. Live score: Kalshi public live_data endpoint (LiveOdds/LiveScore.py; no source timestamp, so freshness is judged on fetch time). The Markov model is validated on the Grand Slam holdout only, so non-slam levels PASS with 'live model unvalidated at this level'.
- Kalshi quotes carry no source timestamp: log `fetched_at` (our clock, UTC) and `price_time = null`. Robinhood-vs-Kalshi price differences are unmeasured.
- Prediction log `data/predictions/<season>.jsonl` is append-only; rows are written only before the scheduled start; `--dry-run` never appends.
- Do not place orders or wagers from this repo. No cloud agents. No GitHub remote yet; **push only when Tim explicitly says OK.** Local commits are fine.
- Data licences: Sackmann data CC BY-NC-SA 4.0 (non-commercial, attribute, share-alike). tennis-data.co.uk: private use only, manual download.
